Velmara — a vintage travel poster for a harbour city that does not exist: a terraced headland above a teal sea at sunset, one landmark (the Lantern Tower), three sailboats, and the place name set in hand-drawn deco capitals. Pure Python 3.13 standard library (no PIL in the grader): own pixel buffer, scanline polygon fill, 2x box downscale, zlib PNG writer. Deterministic — two runs are byte-identical.

## Run it

```sh
python3 main.py
```
